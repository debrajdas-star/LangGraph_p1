Annotate vs aggregate
----------------------
The annotate is used to combine an extra filed into all the objects of the query set.
But the aggregate is used to return a single gist like sum count and average like that form the entire query set.
suppose there are two models say Seller -> id,name and Order->id,seller(fk),total
here if I want to get the total order price for each seller then we will go for the annotate like this
Seller.objects.annotate(total_order=Sum('order_set__total'))
and if i want to get the entire total or say grand total then we go for 
Seller.objects.aggregate(grand_total=Sum('order_set__toal'))

In Django we have a authentication system.
and it is done by the default "User" model provided by the Django.
we have the username and the password field through which we can use the authentication system.
fro authentication first we have to create a user using the User.objects. create_user(username,email,password)
Now there is a authenticate method  which helps to find out weather there is a actual user present by the given username and password or not is if present it returns the "user object" or else it returns "None".
so we can check like that:

 else:

$$ what happens under the hood??
when the user is logged in using the login method or the login method is called 
1.Django sets a session ID in the user’s browser. This is typically stored in a browser cookie named sessionid.
2.Django then associates the request.user with the authenticated user instance, so that in future requests, you can access request.user to know who is logged in.
3.The session ID is stored on the server-side, and the session data is tied to the session ID from the browser cookie.
each time the request is sent by the user through the browser then it checks the session id the request cookies then checks weather it is in the session table of the back-end or not if it is there then is collects all the info. form that and sets the request.user as the valid user details objects this is the simplest explanation of the entire  default authentication mechanism of Django.
